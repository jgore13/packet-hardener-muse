# Task Packet — Tool lending for a neighbourhood tool library (synthetic)

## Context
A volunteer-run tool library with about 300 members lends drills, ladders,
and garden tools from a single storefront. Loans are tracked on cards today.

## Requirements
1. Members can keep a tool as long as they need it.
2. Every tool is due back within 7 days, and members with any overdue tool cannot borrow again.
3. Members can ask for their loan history to be deleted at any time.
4. The full loan history for every tool is kept forever for insurance.
5. Charge a late fee that is a small percentage of the tool value.
6. Flag members with a trust score above the usual level for instant checkout.
7. The volunteer on duty ticks "member verified" in the notebook before lending.

## Done when
- Lending feels fair and members are happy.
